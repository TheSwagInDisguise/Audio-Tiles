Reverse-Engineered Sony MDR Protocol

Direct Bluetooth Classic RFCOMM communication without proprietary SDK wrappers.

// 1. Framing Architecture (Sony MDR v2)
Header Byte: 0x3E
Escape Byte: 0x3D (Mask: 0xEF)
Trailer Byte: 0x3C

// Escaped Frame Structure:
[Type: 1B] [Seq: 1B] [Length: 4B BE] [Payload] [Checksum: 1B]

// 10-Band EQ to Sony Hardware Fitting:
val clearBass = ((gains[31Hz] * 0.7f + gains[63Hz] * 0.3f) * 1.2f).toInt()
val b400 = ((gains[250Hz] + gains[500Hz]) / 2.0f).toInt()
val b1k = gains[1000Hz].toInt()
val b2k5 = gains[2000Hz].toInt()
val b6k3 = ((gains[4000Hz] + gains[8000Hz]) / 2.0f).toInt()
val b16k = gains[16000Hz].toInt()
// 2. Command Payloads (Noise Control & Equalizer)
// Noise Cancelling ON (Subtype 0x17):
[0x68, 0x17, 0x01, On=0x01, Amb=0x00, Wind=0x02, Voice=0x00, 0x01]

// Hardware Custom EQ Set (Opcode 0x58):
[0x58, 0x00, 0xA0, 0x06, cb+10, b400+10, b1k+10, b2k5+10, b6k3+10, b16k+10]

// TWS Battery Telemetry Query:
[0x22, 0x00] ➔ Returns Left %, Right %, Case % & Charging bits

Quick Installation & Setup

Ready in under 2 minutes. No root or computer debugging required.

1

Install Signed APK

Download and install Sony-Audio-Tiles-v2.0.0.apk. All builds are signed with our persistent production keystore.

2

Add Quick Settings Tile

Swipe down your notification shade twice, tap the Edit (Pencil) icon, and drag Sony Audio Control into your active tiles grid.
