Reverse-Engineered Sony MDR Protocol

Direct Bluetooth Classic RFCOMM communication without proprietary SDK wrappers.

// 1. Framing Architecture (Sony MDR v2)
Header Byte: 0x3E
Escape Byte: 0x3D (Mask: 0xEF)
Trailer Byte: 0x3C

// Pre-escaped Frame Layout:
[Type: 1B] [Seq: 1B] [Length: 4B Big-Endian] [Payload] [Checksum: 1B]

// Checksum Formula:
val checksum = (type + seq + (len>>24)&0xFF + (len>>16)&0xFF +
(len>>8)&0xFF + (len&0xFF) + payload.sumOf { it.toInt() }) & 0xFF
// 2. Noise Control Command Payloads (Subtype 0x17)
// Noise Cancelling ON:
[0x68, 0x17, 0x01, On=0x01, Amb=0x00, Wind=0x02, Voice=0x00, 0x01]

// Ambient Sound ON (Level 20):
[0x68, 0x17, 0x01, On=0x01, Amb=0x01, Wind=0x00, Voice=0x00, 0x14]

// Battery Telemetry Query:
[0x22, 0x00] ➔ Returns [0x23, 0x00, Level%, IsChargingBool]

Quick Installation & Setup

Ready in under 2 minutes. No root or computer debugging required.

1

Install Signed APK

Download and install Sony-XM6-NoiseControl-v1.0.2.apk. All builds are signed with a verified persistent keystore.

2

Add Quick Settings Tile

Swipe down your notification shade twice, tap the Edit (Pencil) icon, and drag XM6 Noise Control into your active tiles grid.

3

ColorOS Optimization

On Oppo Find X9 Ultra / ColorOS, open the companion app once and grant "Don't optimize" battery permissions to prevent background suspension.
